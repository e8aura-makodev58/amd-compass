# Screenshot assets

Reference screenshots of the current UI: Live Control Room, Settings → Demo controls,
Analytics, and the Offline fallback. They are **not** produced by `npm run test:e2e`;
the main agent captures them with Playwright against a local server started with forced
provider failures and a scratch data root (no API calls), at 1280px width, and refreshes
them after a visual change. Last refreshed 2026-10-16 for the "Engineering print" redesign.
